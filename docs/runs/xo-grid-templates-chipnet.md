# Five XO Grid templates on chipnet

Written by the run itself (`scripts/xo-grid-run.ts chipnet`). An owner's wallet on the unmodified XO engine, on chipnet, paid from the funding address and with everything that is not given away by design returned to it at the end; no block was made by the run. Each part ran in a process of its own with an empty engine state. The wallet has its recovery arrangement and two backup stores (directories of the run, read and written as a store server's are), and each template was stored in the backup before its first action.

The templates' texts were taken from XO Grid (https://xogrid.vercel.app/api/templates/<identifier>/raw) at run time, 2026-11-22T03:41:34.193Z, and checked with the wallet's own reader to have the identifier asked for. They are not this project's and are kept only in the run's git-ignored folder, as are the engine's invitations, which hold them. The wallet took each in as a person adding a file does; the run then asked as an application's page would: a request naming the template, action, role and values, and for an action on a coin of the application's, the coin by outpoint. Drip Mine's `fund` was asked from the wallet's own list of the template's actions instead.
